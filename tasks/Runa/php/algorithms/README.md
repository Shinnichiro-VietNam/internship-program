# Algorithms (Search & Sort) Assignment for Interns

Welcome! This module focuses on algorithm fundamentals with heavy practice: **complexity analysis**, **searching**, and **sorting**.

**Important Note:**
For the best interest of trainees to gain the most from the internship program.
Using AI tools (e.g., ChatGPT, GitHub Copilot) is strictly limited. Consult your trainer first before using any AI assistance to ensure proper learning and compliance.

---

## 📂 Assignments

1. **Project Structure**
   - Identify the `README.md` and task documentation files in this folder.
   - For the assignment in `tasks_1.md`, create a folder named `task_1/`.
   - Put your PHP source code inside `task_1/` (e.g., `ex_1.php`, `ex_2.php`, ...).
   - Add a markdown file `task_1/notes.md` containing:
     - Your time/space complexity analysis for each exercise

2. **Rules for Coding**
   - Do **not** use built-in sorting helpers for implementation exercises (e.g., no `sort()`, `usort()`) unless the task explicitly says so.
   - Write reusable functions/classes where appropriate.
   - Validate user inputs (empty input, non-numeric values, out-of-range values).

3. **How to Run**
   - Prefer CLI execution:
     - `php ex_1.php`
   - If you build an optional HTML form UI, keep it simple.

## ✅ Expected Results

By completing this module, you should be able to:

- Analyze time and space complexity for common algorithms.
- Implement and compare sorting algorithms: bubble, selection, insertion, merge sort, and quicksort.
- Implement linear and binary search and apply them correctly based on data constraints.
- Write test cases and handle edge cases (empty arrays, duplicates, negative numbers, already-sorted inputs).
